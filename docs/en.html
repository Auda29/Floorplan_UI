01 / FROM IMAGE TO DASHBOARD

One plan.
Your entities.

Multiple floorplans and views keep floors, rooms and groups of devices organised.

01

Draw your rooms

Draw rectangles or polygons. Link them to HA Areas and highlight active rooms in each view.

02

Place entities

Search the entity registry and add markers by selection or drag-and-drop. Choose an MDI icon and the values to display.

03

Read the state

Area aggregates show the average room temperature or the number of open windows. Markers open More-Info, toggle an entity or take no action.

02 / VIEW AND EDIT

For everyday use.
And for building it.

Use the floorplan with a mouse, touch or keyboard in view mode. Pan, zoom and separate views also work on narrow displays.

VIEW

See and use entities

Authenticated users receive view mode. Toggle actions still follow their Home Assistant permissions.

ADMIN EDITOR

Edit floorplans and markers

Only administrators can upload images, save configuration and read the full Area and Entity registries.

Back up your layout. Export configuration as a portable JSON backup with images. Imports are validated and previewed before applying.
03 / SETUP

From HACS
to your first plan.

Add the repository

Add this repository as a custom Integration in HACS.

Install Floorplan UI

Install version 0.4.1 through HACS and restart Home Assistant.

Add the integration

Open Settings → Devices & services → Add integration and select Floorplan UI.

Import a floorplan

Open Floorplan in the sidebar and upload an image or a GLB model as an administrator. Choose Edit to add areas and markers.

HACS · Custom repository, type Integration

https://github.com/Auda29/Floorplan_UI

Requirements

Home Assistant 2025.7.3 or newer. PNG, JPEG, and SVG images up to 4 MB per file, or self-contained GLB models up to 25 MB.

Development status

The 0.x series is in development. Back up existing data before testing. In Edit mode, the Warning Center takes you directly to missing entities and invalid bindings.

GOOD TO KNOW

Before you start.

Do I need a cloud service?

Floorplan UI stores configuration and managed images locally in Home Assistant. The integration needs no additional cloud service.

Can I use multiple floors?

Yes. Manage multiple floorplans and create views filtered by Areas, tags or entity domains.

Is the switch above connected to my home?

The illustration on this website is only a local demo. The integration installed in Home Assistant works with your actual entities.
